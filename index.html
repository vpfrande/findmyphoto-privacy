Privacy Policy

Application: Find My Photo Pro

Last updated: November 18, 2026

1. Introduction

Find My Photo Pro is an Android application that helps users find photographs based on their geographical location and the GPS information stored in their photographs.

This privacy policy explains how the application accesses, uses, stores and shares information.

2. Access to Photographs

The application requests access to photographs stored on the user's device. This access is used to identify photographs, read their metadata, display search results and perform user-requested file operations.

Photographs are processed on the user's device. The application does not intentionally upload photographs to a developer-operated server.

3. Location Information

The application may request access to the device's location to help users find photographs taken nearby.

It also reads GPS coordinates embedded in photograph metadata when available.

Location information is used for photo searches and map-related functionality. The application does not intentionally transmit the user's photograph collection or photo GPS metadata to a developer-operated server.

4. Local Data Storage

The application maintains a local database containing information needed to index and find photographs. This may include file references, timestamps and geographical coordinates.

The database is stored on the user's device and is used to provide the application's functionality.

5. Maps and Third-Party Services

The map feature uses OpenStreetMap map tiles and the Leaflet mapping library. Leaflet resources may be loaded from the unpkg.com content delivery network.

When the map is displayed, the device connects to these external services. The service providers may receive technical information such as the device's IP address, request details and the geographical areas for which map tiles are requested.

These services operate under their own privacy policies:

  • OpenStreetMap Foundation Privacy Policy
  • Cloudflare Privacy Policy (relevant to the unpkg.com service)

6. Exporting and Managing Photographs

Find My Photo Pro allows users to create ZIP archives, copy photographs, move photographs and rename files.

These operations are performed when requested by the user. Exported files may be stored on the device.

When the user chooses to share an exported file, Android's sharing interface is used. The selected receiving application or service may then process the shared file according to its own privacy policy.

7. Advertising and Analytics

Find My Photo Pro does not include advertising functionality. The reviewed version does not implement a developer-operated analytics or tracking service.

8. Data Retention and Deletion

The local photograph index is maintained on the device for application functionality. Users can remove the application's local data through Android settings or by uninstalling the application, subject to Android's backup and storage behavior.

Photographs and files saved outside the application's private storage are not necessarily deleted when the application is uninstalled.

Data held by external map service providers is subject to those providers' own retention policies.

9. Data Security

The application relies on Android's application sandbox, permission system and platform security features. Internet connections to the mapping services use HTTPS.

No method of electronic storage or transmission can guarantee absolute security.

10. Children's Privacy

Find My Photo Pro is a general-purpose photo utility and is not specifically designed for children. The application does not intentionally collect children's personal information for developer-operated advertising or profiling services.

11. Changes to This Policy

This privacy policy may be updated when the application or its data processing practices change. The updated policy will be published on this page.
